# Farm Operations Workflow
Season: field assessment → soil sampling → water assessment → crop suitability → rotation/market scenario → crop/variety plan → budget/risk review → approval.

Daily: collect observations → validate sensor/image quality → update crop state → run scientific models → generate recommendation → review/approve → create authorized mission → execute locally → verify → record cost/outcome.

Exceptions include severe weather, disease outbreak, sensor failure, blocked irrigation, robot fault, GNSS degradation, boundary violation, label mismatch or market shock. Pause affected workflow, preserve safe state, notify responsible people and provide recovery checklist.

Support local languages, low bandwidth and offline operation. Show what the system plans, why, where, with which device/input, limits and stop/recovery controls.
