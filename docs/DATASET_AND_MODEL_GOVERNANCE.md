# Dataset and Model Governance
## Dataset card
Name/version, owner, source, license/terms, consent/legal basis, collection date/location, crop/cultivar/stage, sensor/camera, label taxonomy/annotator qualifications, resolution/units/CRS, sampling, bias, missingness, quality, splits, permitted use and retention.

## Model card
Purpose/users, architecture/version, training data, preprocessing, supported crops/regions/stages, metrics, calibration, subgroup/domain performance, failure modes, abstention, latency/compute, safety impact, validation, deployment/rollback and monitoring.

Do not commit private farm images, identifiable people, precise property coordinates or confidential data without rights and safeguards. Public availability does not automatically permit training or redistribution. Minimize data, restrict access, document retention and support export/deletion.

Check label consistency, duplicates, leakage, class imbalance, geography/season coverage, sensor variation and domain shift. Separate synthetic/augmented data from real field data. Split by farm and time where appropriate.
