# Development Roadmap
Capability-based stages; dates are not guaranteed.

## Phase 0 — Foundation
- [x] Initial vision, architecture, research and module blueprint
- [ ] Verify candidate repository licenses, activity and dependencies
- [ ] Interview farmers, FPOs, agronomists, operators and researchers
- [ ] Select one pilot crop, agro-climatic region and plot
- [ ] Baseline requirements, hazard log, architecture and metrics
Exit: reviewed scope, requirements, architecture, risk register and pilot metrics.

## Phase 1 — Digital farm
Farm/field registry and boundaries; crop-cycle/input/observation records; weather and satellite ingestion; sensor gateway; offline capture; tenancy, audit and export.
Exit: one field represented, observed and audited.

## Phase 2 — Agronomy decision support
Crop/variety profiles; soil-test workflow; crop calendar; ET/water balance; scouting; evidence-bearing recommendations; agronomist approval; model cards.
Exit: reviewed recommendations validated against observations.

## Phase 3 — Controlled automation
Irrigation test rig; independent safety controller/manual isolation; offline watchdog; drone imagery; device identity/OTA; fault injection.
Exit: test-rig automation demonstrated.

## Phase 4 — Robotics simulation
ROS 2 robot model; Gazebo world; localization/navigation; obstacle/fault scenarios; mission authorization; simulated scouting; HIL.
Exit: reproducible simulation/HIL evidence.

## Phase 5 — Supervised field pilot
Site risk assessment/permissions; baseline; supervised rover and irrigation; crop/yield ground truth; reliability, water/input, cost and usability evaluation.
Exit: independent review of measured results.

## Phase 6 — Expanded autonomy and market
Seeding/weeding/application integrations; harvest/grading/storage; regional production/price forecasts; buyer/logistics; multi-farm fleet.
Exit: validated multi-operation workflow with transparent economics and safety case.

## Metrics
Yield/quality vs baseline; water per marketable yield; input use; machine availability/intervention; CV false positives/negatives; recommendation calibration; gross margin/payback; incidents/near misses; data completeness, uptime and offline recovery.
