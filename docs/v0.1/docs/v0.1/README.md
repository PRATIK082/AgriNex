# AgriNex V0.1 Engineering Foundation
This increment establishes system requirements, detailed specifications for all 15 modules, module interface contracts, common data model, farm digital-twin schema, ROS 2/Gazebo scaffolding, API vertical slice and CI.

Start with SYSTEM_REQUIREMENTS, MODULE_REQUIREMENTS, INTERFACE_SPECIFICATIONS, COMMON_DATA_MODEL, DIGITAL_TWIN_SCHEMA and TRACEABILITY_MATRIX. Module specifications are in modules/.

This is a development foundation, not production farm-control software, validated agronomic advice or certified robotics. Read AGENT_DEVELOPMENT_GUIDE before using coding agents.
