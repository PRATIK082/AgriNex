# Contributing
Open/identify an issue and module ID. Review existing interfaces before adding dependencies. Check provenance and license compatibility for code, datasets, model weights, images, CAD and documents. Agronomic changes cite authoritative evidence and specify crop, cultivar, soil, climate, stage and region. Physical-operation changes require hazard analysis and safe-state design.

Lifecycle: requirements → architecture → design → implementation → review → unit/integration tests → simulation → HIL → controlled field validation → release evidence.

PR checklist: scope/rationale; license/provenance; requirements/interfaces; tests; safety/security/privacy review; simulation/field evidence where relevant; docs/changelog. Never claim certification or validation without evidence. Do not test experimental autonomy near people/animals/roads/live crops without approved controls, E-stop, supervisor and permissions.
